- HTML5
- CSS3
- Git
- GitHub

## 📚 O que pratiquei neste projeto

- Estruturação de páginas com HTML
- Estilização com CSS
- Classes e seletores
- Box Model
- Flexbox
- Responsividade
- Efeitos com `:hover`
- Versionamento de código com Git
